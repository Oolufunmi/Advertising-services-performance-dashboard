### Objective
- To analyze advertising spend, frequency, and efficiency across brands, media types, time slots, and languages using verified media logs for January 2022.

### Tools
- Tableau Public

- Microsoft Excel (for data cleaning and formatting)

### Data Cleaning
- Removed duplicate and irrelevant records

- Standardized brand and media type names

- Converted duration to numeric (in seconds)

- Cleaned inconsistent date and time formats

- Formatted rate and spot count for analysis

### Exploratory Data Analysis
- Checked distributions of spend across brands

- Analyzed cost patterns by date, timebelt, region, and media

- Identified outliers in cost per second

- Examined language and channel breakdowns

### My Data Analysis Approach
- Grouped data by brand, time, region, and language

- Aggregated spend and count metrics

- Calculated cost per second using rate ÷ duration

- Used visual dashboards to highlight patterns and differences

- Compared media types (Cable, Radio, TTV) in terms of both cost and spot count

### Result and Findings
- Terra and Maggi had the highest spend overall

- Maggi paid the highest cost per second

- Knorr aired the most spots

- Week 4 and Saturdays had the highest ad spend

- Cable accounted for the majority of total media spend

- English was the dominant language, but Hausa and Pidgin appeared in niche campaigns

- ROS was the top program block by spend

- 30-second ads were most used; 5-second ads had the highest cost per second

### Ideas for Deeper Analysis
- Compare actual airtime vs scheduled spots

- Add audience reach or engagement data if available

- Include product category or campaign type segmentation

- Track ad performance over a longer period (monthly or quarterly trends)

### Recommendations
- Optimize high-cost slots by tracking performance ROI

- Consider shifting some spend from premium spots to cost-effective durations

- Use regional and language targeting more intentionally

- Reduce overdependence on ROS if not delivering value

- Balance spend across weekday and weekend to maximize reach

### Recommendation Summary
- Reduce inefficiencies in placement, explore underutilized regions/languages, and review high-cost program blocks to improve cost per spot and overall media value.
